# Leah Reynolds — Professional Portfolio

A responsive, static HTML/CSS portfolio for health and safety coordination, quality systems, and operational improvement. Navy styling, rounded portrait, career story, selected work, full expandable experience, credentials, contact links and downloadable resume.

## Open locally

Double-click `index.html`. All content works without a build step, JavaScript, external fonts or an internet connection (except external contact links).

For an HTTP preview, run `python -m http.server 8080` from this folder, then open `http://localhost:8080`.

## Files

- `index.html` — page content and accessible native expand/collapse sections.
- `styles.css` — visual design, mobile layouts, focus states, reduced-motion and print rules.
- `assets/` — supplied portrait, favicon and latest approved PDF resume.
- `.nojekyll` — serves the site as plain static files on GitHub Pages.
- `documents/` — setup, editing and deployment notes.

See [the setup guide](documents/SETUP.md) for GitHub Pages publishing steps and [the editing guide](documents/EDITING.md) for future changes.

Deployment status is recorded in [STATUS.md](documents/STATUS.md). Do not assume the site is published until that file identifies a verified deployment.
